# life-hacks: My Coding Solutions for Daily Life

This repository is a collection of utility codes and Jupyter notebooks that I created myself - to solve inconveniences and boost efficiency in daily life.

## Project/Notebook List

* [Latest Paper Summarizer](latest_paper_summarizer/)

    A script that automatically fetches the latest papers related to user-input keywords from the web and summarizes their core content.
* [Hanja Flashcard Generator](hanja_flashcard_generator/)

    Helps learning by generating customized flashcards from a specific list of Hanja characters.
